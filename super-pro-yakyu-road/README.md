# スーパープロ野球ロード（形を作る段階）

野球ゲーム。いまは独立したゲームとして作っていて、完成したら「ドット芸能界＆政治界 ライフスペシャル」（`../dot-geinou-v2`）に合体させる予定です。

## あそびかた

`index.html` をブラウザで開きます（ES モジュールなので、`python3 -m http.server` などのサーバー経由で開いてください）。
1ファイル版は `python3 tools/build.py 出力.html` で作れます（esbuild を npx で使います）。

- **タイトル** → **ペナント（新しく始める）**：球団 → 試合数（30／60／143）→ リーグのバランス（投高・標準・打高・超打高）
- **拠点**：試合をする／試合を飛ばす（結果だけ）／7日まとめて進める／順位表／選手一覧・能力／成績ランキング／最近の試合結果／設定（バランス）／セーブ／タイトルへ
- **試合（攻撃）**：十字キーでミートカーソル、A でミート打ち、B で強振（カーソルが小さい代わりに強い打球）。ボールがカーソルの中心より下ならゴロ、上ならフライ。早く振れば引っぱり、遅ければ流し打ち。
- **試合（守備）**：↑↓ で球種、A で決定 → 十字キーでコース → A で投げる。コントロールが低いと、ねらいがずれる。変化球は最後に曲がる。
- **START**：この回をオート／試合終了までオート／投手交代
- 操作：キーボード（矢印・WASD／Z・Space・Enter／X・Shift／Esc・C）、画面のボタン（スマホ）、タップ（決定）

## 球団・選手

- セ・リーグ：横浜ベイスターズ、広島東洋カープ、東京ヤクルトスワローズ、阪神タイガース、中日ドラゴンズ、読売ジャイアンツ
- パ・リーグ：福岡ダイエーホークス、近鉄バファローズ、オリックスブルーウェーブ、北海道日本ハムファイターズ、埼玉西武ライオンズ、千葉ロッテマリーンズ
- 球団は名前と球団カラー、帽子の頭文字だけで表しています（ロゴ・マスコットの画像は入れていません）。選手はすべて架空の名前で、能力は毎シーズン自動で作られます。
- 能力：野手 ミート・パワー・走力・肩力・守備力・捕球（S〜G）と弾道、投手 球速・コントロール・スタミナ・変化球（7段階）。

## 構成（開発者向け）

```
index.html / style.css
js/core.js     画面（960x540・拡大・高解像度）、ループ、場面の重ね、入力（キー・画面ボタン・タップ）、効果音、乱数、描画の部品
js/data.js     12球団・リーグ・選手名・能力と評価・球種と変化・選手と球団の生成・バランス（BALANCE）
js/game.js     1試合のルール（カウント・アウト・走者・得点・延長12回で引き分け・サヨナラ）、投手交代、勝敗投手、成績、
               1打席の確率モデル（simPA：コンピュータの試合）
js/league.js   ペナント（日程・1日の試合・順位・ランキング・セーブ）。合体用の差し込み口 SPR_HOOKS（onDay / onGame）
js/draw.js     ちびキャラ（オリジナルデザイン）、打席の画面、上から見た球場、スコアボード、能力バッジ
js/scenes/match.js    操作する試合（打撃・投球・打球の判定 battedBall / judge・オート・投手交代）
js/scenes/pennant.js  タイトル・ペナント開始・拠点・順位表・選手一覧・ランキング・試合結果・設定・シーズン終了
tools/build.py 1ファイル版を作る
test/          sim_check.mjs（143試合を自動で回して、打率・本塁打・得点・防御率を確かめる）、ui_t1.mjs（画面を一通り）、bundle_smoke.mjs
```

標準バランスでの143試合の目安（自動計算）：打率 .26、1試合の得点 3.9、本塁打 1.0、三振率 19%、防御率 3.9。
投高は得点 2.7、打高は 5.4、超打高は 7.3 くらい。

テスト用：`window.__spr`（エンジン・リーグ・試合・データ）、`window.__ff(n)`（n フレーム進める）、`window.__pause(true)`。

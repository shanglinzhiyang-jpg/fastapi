# ドット芸能界&政治界　ライフスペシャル

（旧タイトル：ドット芸能界 〜めざせ！国民的スター〜（v2））

事務所やテレビ局、劇場、撮影所でお仕事・レッスン・オーディションをこなしながら「国民的スター」を目指し、
選挙に立って **政治家** にもなれる 2D ドット絵 RPG です。暮らし・人間関係・家族に加えて、日本の社会の
**表と裏**（借金と闇金、反社会的勢力、スキャンダル、裏金と、その先の警察・検察・裁判・刑務所）までを描きます。
ブラウザだけで動きます（ビルド不要）。

v2 では、画面が **640×360 の高解像度ドット絵** になり、芸能活動に **暮らし（ライフシミュレーション）** が加わりました。

- **生活ステータス**：体力に加えて「満腹」「ストレス」「身だしなみ」の3つのゲージ。食事・お風呂・息抜きで整えると、ミニゲームの調子が上がります
- **暮らしとキャリア**：曜日つきの日付、毎週月曜の家賃、引っ越しと家具、自炊、ドット商店街での買い物と趣味。
  ファン、SNS「ドッター」、レギュラー番組、自分の冠番組、毎週の好感度ランキング
- **人間関係**：16人の仲間と、話す・プレゼント・おでかけで仲良くなれます。ハートイベント、相方、「大切な人」も
- **スマホ**：メッセージ・連絡先・予定・家計・ドッター・家族・「政治」・「借入・返済」
- **政治界**：区議会・都議会・区長・都知事・衆議院・参議院の選挙、政党（自由民主党・民主党と架空の政党、自分の新党）、
  国会と法案、内閣と総理大臣、政策と経済、政治とお金。舞台は東京の北の「永田町・霞が関」（下記「政治の遊び方」）
- **社会の裏側と法**：犯罪を選べば、現実と同じように逮捕・起訴・裁判・刑務所と前科。消費者金融と闇金、自己破産、
  反社会的勢力、喫煙・飲酒のルール。舞台は東京の南の「ネオン街」と、永田町の警視庁・検察庁・裁判所（下記「社会の裏側と法」）

時間帯や季節はありません。ベッドで寝るまでが「その日」で、寝ると次の日（曜日がひとつ進む）になります。

## プレイガイド

### 目標

知名度（★）を上げて、まずは **★4000**（国民的スター）を目指します。★4000 に届いて街に出ると NHK から電話がかかり、
NHK放送センターで年末の大型歌番組に出演。これは大きな節目のお祝いで、**エンディングはありません**：
「国民的スターになった！でも、芸能人生はまだまだ続く」――そのままキャリアを築き続けます。

称号：無名 → 駆け出し（★30）→ 若手（★100）→ 注目株（★250）→ 人気者（★500）→ 売れっ子（★1000）→ スター（★2000）→ 国民的スター（★4000）
→ 大スター（★7000）→ 大御所（★12000）→ レジェンド（★20000）→ 芸能界の宝（★35000）→ 永遠のスター（★60000）

年末の歌番組のあとは、てちょうの「もくひょう」に **キャリアの目標** が並びます（どれも次の段階があります）：
次の称号、ファン（〜100万人）、冠番組の放送回数（10・30・50・100回の記念）、レギュラー番組の数（最大4本）、
好感度ランキング1位の通算週数、なかよしの仲間の数、そして **ドット芸能大賞**。

**ドット芸能大賞**（架空の賞）：120日ごと（121日目・241日目…の朝）に、その「一年」の活躍（増えた★とファン、
レギュラー番組の収録、冠番組）で 大賞／最優秀タレント賞／優秀タレント賞／話題賞／新人賞（最初の年だけ）が決まり、
賞金・ファンのほか、授賞式のお祝いがあります。発表の1週間前にニュースでお知らせ。大賞を3回とると **殿堂入り**。

芸能の道とならんで、**政治の道** もあります。25歳（参議院・知事は30歳）から選挙に立候補でき、議員・大臣、
そして総理大臣をめざせます（下記「政治の遊び方」）。どちらの道も、まっとうに歩くのも、危ない近道に手を出すのも自由ですが、
近道の先には現実と同じ結末が待っています（下記「社会の裏側と法」）。

はじめは所持金 ¥3,000・おにぎり2個。ドット荘（自宅）の部屋からスタートします。
部屋の前にいる大家さんに話しかけると、暮らしの基本を教えてくれます。

### はじめに：キャラクターをつくる

「はじめから」を選ぶと、まず「はじめる前に」のカード（フィクションであること、実在の企業・政党は場所や名前として登場するだけで
実在の政治家は出ないこと、犯罪はすすめるものではなく重い結果があること、脅迫や襲撃・借金の取り立て・スキャンダルなどつらい場面もあること、
お酒とタバコは20歳から、現実で困ったときの相談先（警察相談 #9110・消費者ホットライン 188・法テラス））が出ます。
A（Z・Enter）でつぎへ、B（X）でタイトルにもどります。
つづいて、4ページのキャラクター作成になります（右上の 1〜4 が今のページ。B でひとつ前のページへ）。

1. **見た目**：髪型・髪の色・肌の色・トップス・ボトムス・スカート・めがね（家のクローゼットでもあとから着がえられます）
2. **プロフィール**
   - **姓・名**：A で入力（ゲームの中の入力欄）、◀▶ で候補から選ぶ。まわりの人からは「名」で呼ばれます
   - **性別**：男性／女性／ないしょ　**年齢**：15〜40さい（ゲームの1年＝120日。120日ごとに誕生日で、家族からお祝いのメッセージ）。
     お酒・タバコは20さいから、選挙に立候補できるのは25さいから（参議院・知事は30さい）。25さい未満で始めると、立候補まで「あと○日」が出ます。
     25さい・30さいの誕生日には、立候補できる選挙がふえたことを朝のメモで知らせます
   - **出身**：47都道府県（◀▶、A で次の地方へ）。ふるさとの家族から名産品が届くことも
   - **性格**：それぞれ小さな特徴があります（下の表）
   - **時代**：昭和（1980年代）／平成（1990年代）／平成（2000年代）／令和（いま）。ふんいきとお金の表示、そして政党・選挙・法律のしくみが変わります（下記）

### 1日の流れ（例）

1. 朝：スマホを見る（友だちのおさそい、番組のオファー、家賃の明細）。HUD のゲージを確認

4. お風呂でさっぱりして、夜はベッドで寝る → 体力全快・次の日に・自動セーブ

### お仕事と★の段階

お仕事はミニゲームで、結果のランク（S/A/B/C/D）でギャラ・知名度・ファン・スキルが決まります。
告知の「ギャラ 目安¥3,000（出来で変動）」はランク B の額です。

| 段階 | 条件の目安 | ギャラ（B） | 知名度 |
| --- | --- | --- | --- |
| 0 | だれでも（公園の路上ライブ、前説、エキストラ、バイト…） | ¥500〜1,500 | 3〜8 |
| 1 | 所属 または ★30 | ¥3,000〜6,000 | 10〜25 |
| 2 | ★250 | ¥8,000〜15,000 | 30〜60 |
| 3 | ★1000 | ¥20,000〜40,000 | 80〜150 |
| 4 | ★2000 | ¥50,000〜80,000 | 150〜300 |

ランクの倍率：S ×1.5 / A ×1.2 / B ×1.0 / C ×0.7 / D ×0.4。
お仕事のたびに 満腹 -10・ストレス +8・身だしなみ -10（ランク S ならストレス -4 のおまけ、D なら +3）。

### レッスンと自主練

- **レッスン**：各施設で ¥2,000〜8,000、スキル +3〜6（ミニゲームつきのレッスンは出来しだいで増減）
- **自主練**：家のパソコンで無料・体力 -10・スキル +1（1日3回まで）
- **プロの個別指導**：家のパソコンで ¥20,000・体力 -15・スキル +5（1日1回）
- 家具の本棚（トーク +1）・ドレッサー（演技 +1）・防音ブース（歌 +3）、カラオケ（歌 +1、1日3曲まで）でも伸ばせます

スキルは お笑い／演技／歌／トーク（最大100）。高いほどミニゲームがやさしくなります。

### 政治の遊び方

芸能人のまま、選挙に立って **政治家** にもなれます。中身は `js/engine/politics.js` のシミュレーションで、
選挙制度・議席の数・供託金・省庁の名前などは、えらんだ時代とゲームの中の年に合わせて変わります
（政治の1年 ＝ ゲームの120日、1か月 ＝ 10日）。入口は **スマホの「政治」アプリ**（ダッシュボード）と、
東京の北の **永田町・霞が関**（国会議事堂・首相官邸・党本部）、商店街の **ドット区役所**（選挙管理委員会）です。

#### 1. 立候補まで

- **被選挙権**：区議会議員・都議会議員・区長・衆議院議員は25歳から、参議院議員・都知事は30歳から。
  **選挙権**（投票）は20歳から（2016年からは18歳から）。公民権停止中や刑の執行中は、立候補も投票もできません
- **政党**：党本部の受付で入党すると、2階の選挙対策本部で **公認**（党の候補者）を申請できます。
  議席を持つ現職がいる選挙区は、その人が優先。参議院の比例代表は、知名度のある人にとって入りやすい入口です。
  無所属でも立候補できます（党の組織票はないが、しがらみもない）
- **新党**：永田町の貸しオフィス（不動産会社の人）かスマホの「政治」アプリで、党名・略称・色・エンブレム・公約を決めて結党できます。
  法律の上で「政党」と認められる（政党交付金が出る）のは、国会議員5人以上か、国会議員1人以上で直近の国政選挙の得票率2%以上のとき
- **立候補の届出**：「政治」アプリの選挙、党本部の選挙対策本部、区役所の選挙管理委員会から。
  **供託金**（衆院小選挙区・参院選挙区・知事 300万円、比例代表 600万円、区長 100万円、都議 60万円、区議 30万円 など。
  時代によって変わる）を政治資金から、足りなければ所持金から納めます。得票が少ないと没収されます
- 議員がほかの選挙に立候補すると、届出の日に今の職を辞めたことになります（公職選挙法90条）

#### 2. 選挙

- 衆院選・参院選は「公示」、ほかの選挙は「告示」の日から選挙運動ができます（衆院12日、参院・知事17日、区長・区議7日 など）。
  それより前は「政治活動」（地元回り・後援会・街頭演説など）だけで、効果は半分
- **選挙運動**：街頭演説・ポスター・選挙カー・討論会・SNS（ネット選挙は2013年から）・握手・後援会・政党のネット広告・献金集め。
  体力とお金を使い、トークの力と知名度・地元の支持が効きます。永田町の駅前の演説スポットでも演説できます
- **買収**（票をお金で買う）と **戸別訪問** は公職選挙法違反です。選ぶこともできますが、捕まれば逮捕・裁判。
  有罪になれば公民権停止で、何年も選挙に出られなくなります
- **情勢調査** で見込みがわかります。投票日の翌朝に開票速報と結果が出ます。衆院の重複立候補なら、小選挙区で負けても比例で復活当選することも

#### 3. 議員生活

- **歳費・報酬**：毎月（10日ごと）所持金に入ります。調査研究広報滞在費・政務活動費などは **政治資金**（自分のお金とは別）へ。
  事務所の経費と私設秘書の給料は政治資金から出ていきます
- **国会**：通常国会は毎年1月から150日（1991年の国会法改正までは12月の召集でしたが、ゲームではどの時代も1月）。会期中は国会議事堂に出席して、本会議で法案に賛成・反対（党の方針に背くと党内の評価が下がる）、
  委員会で質問（トークの力しだい）。長く欠席すると批判されます。国会見学と本会議の傍聴は、だれでもできます
- **地元と評判**：地元回り・陳情・後援会づくり・記者会見（失言に注意）・視察。評判・地元の支持・党内の評価が次の選挙と出世を決めます
- **政治とお金**：政治資金パーティー・寄付で資金を集め、毎年 **収支報告書** を出します。報告書に載せないお金（**裏金**）は
  政治資金規正法違反。見つかれば特捜部の捜査・起訴、有罪なら公民権停止で失職することもあります。
  業者の「お願い」に応じてお金を受け取るのは収賄です
- 任期（衆院4年・参院6年・地方4年）が終わると選挙。衆議院は解散されることもあります

#### 4. 党・政策・内閣

- **政策**：20の分野・85の政策（消費税率・年金・子育て・防衛・エネルギー・憲法 など）。どの政策も、得をする人と負担する人がいる
  「トレードオフ」で、若者・高齢者・会社員・自営業・農林漁業・都市・地方・無党派層 など11の層の支持と、経済（成長率・物価・失業率・
  財政・円相場・株価）に効きます。どれが正しいかは、ゲームは決めません
- **法案**：議員立法は賛成者（衆院20人・予算を伴えば50人、参院10人・同20人）を集めて提出 → 委員会 → 衆議院 → 参議院で可決して成立。
  閣僚になると内閣提出法案（閣法）も出せます。ねじれ国会、衆院の再可決（3分の2）、予算の自然成立もあります
- **党内**：派閥・グループに入る、党役員（幹事長・政調会長 など）の打診、党首選。自分の党なら党首室で運営・議員の勧誘・公約の見直し
- **内閣**：総理や党首から **入閣の打診** が来ることがあります（スマホに届く）。閣僚は閣議（官邸、火・金）と国会での答弁。
  **総理大臣** は国会議員の中から国会が指名し、組閣・内閣改造・連立協議・予算編成・衆議院の解散・総辞職・外遊を決めます。
  内閣不信任案が可決されたら、10日以内に解散か総辞職です
- 支持率は世論とともに動き、大地震・台風・景気後退・円高・円安などの出来事でも変わります。人気のない内閣が続けば政権交代も起こります

### 社会の裏側と法

ゲームの中では、犯罪や危ない誘いを「選ぶ」こともできます。でも、それは **すすめるものではありません**。
日本の現実と同じように、捕まれば警察・検察・裁判所・刑務所へ進み、仕事も家族の気持ちも失いかねません。
手口のくわしい描写はなく、選んだ結果だけが描かれます。テロや要人の暗殺は、プレイヤーが選べる行動には **ありません**。

#### 犯罪と処罰

- 罪は実際の罪名・条文・法定刑で扱います（その時代の法律。2025年6月からは懲役・禁錮が「拘禁刑」に）。
  万引き・無賃乗車・暴行・傷害・強盗・飲酒運転・賭博・特殊詐欺の受け子・口座の売却・脱税・裏金（不記載）・収賄・贈賄・
  口利き・選挙の買収・戸別訪問・証拠隠滅 など
- その場で捕まらなくても、防犯カメラ・被害届・税務調査・告発・週刊誌から、あとで発覚することがあります
- 流れ：逮捕（48時間）→ 送検（24時間）→ 勾留（10日＋延長10日）→ 起訴／不起訴／略式起訴（罰金）→ 公判 → 判決
  （罰金・執行猶予・実刑・無罪）→ 控訴・上告 → 刑務所（刑務作業・面会・仮釈放）。軽いものは微罪処分や過料・補導で終わります。
  国会議員や首長の「政治とお金」の事件は特捜部が独自に捜査し、検察官が逮捕します（送検はなく、48時間以内に勾留請求）
- **結末**：前科がつく、事務所の契約が切られる、レギュラー番組を降板、活動自粛やテレビの起用見送り、ファンが減る。
  議員は禁錮（拘禁刑）以上の実刑や、公民権停止（選挙・政治資金の罪、在職中の収賄）で失職します。**執行猶予中** にまた罪を犯して実刑になると、猶予が取り消されます
- 警視庁で自首、検察庁や裁判所で手続き、裁判の傍聴もできます。てちょうの「くらしと法」で、いまの状態と記録が見られます

#### 借金と破産

- **消費者金融**（ネオン街のドットローンなど、架空の会社）と **銀行カードローン** は合法の貸し手。審査があり、利息は法律の上限まで
  （2010年6月からは利息制限法の15〜20%、借入れは「総量規制」で年収の3分の1まで。それより前の時代は「グレーゾーン金利」の時代）
- **闇金** は違法な業者。トイチ（10日で1割）の利息と取り立てで、暮らしがこわれます。借りてしまったら、ひとりで払い続けず、
  警視庁の相談室や弁護士（スマホの「借入・返済」→ 法律相談）、区役所の多重債務相談へ
- 返済が遅れると信用情報に事故の記録が残り、しばらく借りられなくなります。どうにもならなければ **任意整理・個人再生・自己破産**
  （裁判所の破産係。免責が決まれば返済は免除されるが、その後しばらく新しい借入れはできない）

#### 反社会的勢力

- ネオン街の裏通りには **鬼灯組**（架空の暴力団）の事務所があります。甘い話や「お礼」を受け取れば、それが弱みになります。2011年10月までに全国でそろった
  **暴力団排除条例** のもと、反社会的勢力との交際がわかれば、芸能人は契約解除や引退、政治家は離党や辞職に追いこまれます
- 困ったときは警察へ。断る勇気が、いちばんの身の守り方です

#### 思わぬ出来事

暮らしていると、ときどき社会の裏側の出来事が向こうからやってきます（はじめの数日はなし。危ない借金・前科・夜の街通い・
裏金などがあるほど起きやすく、それでも数日に1回まで）。どの出来事でも、いちばん上の選択肢がまっとうな道です。

- **事故**：交差点や自転車での事故、舞台や収録の事故（救護・届け出・保険・賠償）
- **事件**：特殊詐欺の電話、空き巣、ストーカー（警察に相談）、ひったくりの目撃と裁判での証言
- **週刊誌のスクープ**：夜遊び、もみ消し、反社との写真、裏金。謝罪会見で何を言うか
- **政治家への誘い**：料亭の接待、口利きの依頼、派閥のパーティー券のキックバック（架空の政党だけ。実在の政党が悪事をする場面はない）
- **反社会的勢力**：闇営業の誘い、闇バイトの勧誘、恐喝。断って、警察へ
- **脅迫と警備**：脅迫状や、未遂に終わる襲撃（架空の単独の人物。けがで入院することも）。プレイヤーは守られる側で、
  総理や大臣なら危機への対応を決めます。テロや暗殺をプレイヤーが起こすことはありません
- **借金の取り立て**：家族や職場に及ぶ闇金の取り立て（貸金業法は、正当な理由のない夜9時〜朝8時の取り立てや勤務先への連絡を禁じている）

#### 喫煙・飲酒

- タバコとお酒は **20歳から**（成年年齢が18歳になった2022年4月以降も、20歳のまま）。20歳未満は補導されます。
  タバコはお店で年齢を確認されて買います
- 吸える場所には決まりがあります：路上喫煙を条例で禁止する地区（千代田区は過料2,000円）、駅の構内、2020年4月からの原則屋内禁煙
  （改正健康増進法）。吸うなら喫煙所で。吸いすぎると習慣になり、体力の最大値が下がります
- お酒は飲みすぎると泥酔・迷惑行為に。飲んだら運転してはいけません（飲酒運転）

### 実在の政党の扱い

- 実在の政党として登場するのは **自由民主党**（1955年11月15日結党。すべての時代）と **民主党**（1998年4月27日結成〜2016年3月27日に他党と合流。
  その時代だけ）の2つだけです。党本部の場所・ロゴの看板・結党の経緯・党首の呼び名（総裁・代表）など、確かめられる事実だけを中立に書いています
- **実在の政治家は登場しません**。総裁・代表・幹事長・大臣・議員は、すべてゲームが作る架空の人物です。実在の政党や人物の不祥事を描くことはありません
  （ゲームの中のスキャンダルは、架空の人物とプレイヤー自身に起きる出来事です）
- ほかの政党（ともしび党・青空党・日輪党・にじいろ党・田園党・かけはし党）は架空です。名前・ロゴ・政策・人物は実在の党と関係ありません。プレイヤーの新党の名前も、実在の党に似せたものはつけられません
- 各時代のはじめの議席の配分（与党と野党の大きさ）は、シミュレーションの出発点として、その時期の国会の勢力図に近い数にしてあります。架空の党の議席数が、特定の実在の党を表すわけではありません
- 議席・支持率・政権の行方はシミュレーションで、史実どおりには進みません。政策の効果は、どの立場にも得と損があるように作ってあります

### てちょう

- 寝たとき、建物から街に出たとき、引っ越しのときなどに **自動でセーブ** されます。メニューの「セーブ」でいつでも保存できます

### 画面と座標

- 画面は **640×360（SW×SH）** の論理ピクセル。エンジンが端末の解像度に合わせて整数倍に近い倍率で拡大します（`display.S`）
- マップの世界座標は v1 と同じ **ユニット**：1タイル = `TILE` = 16 ユニット。世界は `UNIT` = 2 倍で描かれるので、
  1ユニット = 画面の2ピクセル、見える範囲は 320×180 ユニット。タイルとキャラの絵は **2x ネイティブ**（タイル 32px、キャラ 32x40px）
- **シーン** は `{ update(g), draw(ctx, g), opaque, hd, hidesHud }` のふつうのオブジェクト。`g.push(scene)` / `g.pop(scene)`
  - `hd: true`：640×360 の画面ピクセルで描く（新しいシーンはすべてこれ）
  - `hd` なし：v1 の 320×240 空間で描き、1.5 倍で中央に表示（`opaque` なら左右に飾りの帯）。古い演出とミニゲームの互換用
  - `hidesHud: true`：開いている間、マップの HUD（高さ `HUD_H` = 46px）を描かない
- 部屋の `drawUnder / drawOver(ctx, g, cam)` と prop の `draw(ctx, sx, sy, g, e)` はユニット座標（2倍の変換の中）。
  ネイティブ HD の絵は、2倍の大きさのキャンバスに描いて `ctx.drawImage(cv, x, y, cv.width / 2, cv.height / 2)` で置きます
  （`props.js` の `bake` / `blit`、家具の `paint` がこの方式）。0.5 ユニット = 画面の1ピクセル
- 画面に収まる小さな部屋は、上の壁が HUD に隠れないよう少し下にずらして表示されます（大きい部屋は `topPad`）

### 場所（place）の定義

```js
import { registerPlace } from '../engine/map.js';
import { LOOKS } from '../engine/sprites.js';

registerPlace({
  id: 'nhk',                  // 街の建物の place と一致させる
  name: 'NHK放送センター',     // 入った時のバナー
  kind: 'building',           // 'town' | 'building'
  bgm: 'studio',
  start: { room: 'lobby', x: 7, y: 9, dir: 'up' },  // 入った時の位置
  rooms: {
    lobby: {
      floor: 'floor_marble', wall: 'white',   // 既定レジェンドで使われる
      tiles: [
        '###############',
        '=w===p===p===w=',
        // ... 1文字 = 1タイル
        '######MMM######',
      ],
      legend: { C: 'counter_white', P: 'plant', S: 'sofa_blue' },
      entities: [ /* npc, sign, prop, logo */ ],
      warps: [ { x: 6, y: 10, to: 'exit' }, { x: 13, y: 2, room: 'studio', tx: 2, ty: 8, dir: 'up' } ],
      events: [ { x: 3, y: 4, on: 'action', run: async (g) => { ... } } ],
      onEnter: async (g) => { ... },     // 部屋に入るたびに実行
      topPad: 24,                        // 大きい部屋：カメラが上端より少し上まで動ける（HUD対策）
      bgm: 'studio',                     // 部屋ごとに変えたい場合
      bg: '#000', drawUnder(ctx, g, cam) {}, drawOver(ctx, g, cam) {},  // 背景色・自由描画（ユニット座標）
    },
  },
});
```

**既定レジェンド**：`.` 床（room.floor）、`#` 壁の上面（walltop_<wall>）、`=` 壁の正面（wall_<wall>）、
`w` 窓付き壁、`p` ポスター付き壁、`c` 時計付き壁、`M` 出口マット、`d` 木のドア、`g` ガラスドア、` ` 何もない。
レジェンドの値は `'floor_wood+desk'` のように `+` で重ねられます。`obj` タイル（家具など）だけを書くと、
自動的に room.floor の上に描かれます。

**部屋の作法**：1行目は `#`（壁の上面）、2行目は `=`（壁の正面。窓・ポスター・ロゴ看板を飾る場所）、
左右の端と最下段も `#`。出口は最下段の `M` に `{ to: 'exit' }` ワープを置く（街の建物の前に戻る）。
3/4 見下ろし視点なので、キャラは壁の正面の1つ下の行から歩けます。

**エンティティ**
- `{ type: 'npc', id, x, y, dir, look, name, text: '…' | ['…', '…'], talk: async (g, npc) => {}, wander: 2, cond: (g) => bool, fixedDir, person: 'jiro' }`
  （`person` があると、話しかけは人間関係のメニューを通ります。`wander` の NPC は、建物のドアとその前のマス、ワープの隣のマスには止まりません）
- `{ type: 'sign', x, y, text | talk }` 見えない調べるポイント（看板タイルの上などに置く）
- `{ type: 'prop', x, y, w, h, draw(ctx, sx, sy, g, e), solid, text | talk }` 自由描画の大きな物
- `{ type: 'logo', x, y, w, h, logo: 'nhk', board: true, text | talk }` 壁などに掛けるロゴ看板（タイル単位、小数可）
- `{ type: 'building', x, y, w, h, door, place, name, kind, ... }` 町の建物（下記）

**ワープ**：`{ x, y, to: 'exit' }`（街へ戻る）／`{ x, y, room, tx, ty, dir }`（同じ施設の別の部屋）／
`{ x, y, place, room, tx, ty, dir }`（別の施設）。`check: async (g) => bool` で false を返すと押し戻されます。

**イベント**：`{ x, y, w, h, on: 'action' | 'step', run: async (g) => {}, once: 'フラグ名', cond: (g) => bool }`。
`action` はその位置に向かって A ボタン、`step` は踏んだ時。

**カウンター越しの会話**：`counter` / `counter_white` / `register` は `talkThrough` タイルなので、
カウンターの奥の NPC に手前から話しかけられます。

**町の建物**：町の部屋の entities に `{ type: 'building', x, y, w, h, door, place, name, kind, logo | sign, wall, roof, ... }`。
足元の w×h タイルは通れず、ドアのマス（`x + door, y + h - 1`）が入口。`kind` は
`office hotel tower theater studio house shop small bath station` など（`buildings.js` の先頭に一覧と見た目のオプション）。
`g.exitPlace()` はこの建物のドアの前に戻ります（`doorIndexFor`）。

### タイル

```js
import { defineTile, R, P, outline, bevel, shadowEllipse } from '../engine/tiles.js';

defineTile('myplace_sofa', {
  solid: true, obj: true,              // 通れない／床の上に重ねて描く
  draw(c, r, frame, variant) { ... },  // 16x16 の v1 の絵（なくてもよいが、tileImage() で使われる）
  hd(c, r, frame, variant) { ... },    // 32x32 のネイティブ HD の絵。マップはこちらを使う
});
```

- `hd()` がないタイルは、16px の `draw()` を **Scale2x** で 2x にして使います（`hdify.js`）
- HD の作法（組み込みタイルはすべて `hd()` あり）：32×32、光は左上から、素材ごとに2〜3トーン、物には1pxの暗い輪郭（`outline()`）、
  ディザは質感にだけ。床・地面・壁はつなぎ目なく敷けるように（`Rw` / `Pw` で折り返し描画）
- ほかのオプション：`talkThrough`、`frames` / `speed`（アニメ）、`variants`（マスごとにランダムな絵柄）
- ヘルパー：`R P Rw Pw pix speckle disc oval ring line bevel inset dither grain outline blobs ramp shadowEllipse`、壁の色 `WALL_THEMES`
- 独自タイルの ID は `'<施設ID>_xxx'`

`career.js` が登録）がてちょうに渡します。ドット芸能大賞は `flags.career_award`（120日ごと・大賞3回で殿堂入り）。

### プロフィールと時代（`js/engine/profile.js`）

- `g.state.profile = { familyName, givenName, gender: 'm'|'f'|'x', age, hometown, personality, era, family: [{ id, rel, name, alive, cause }] }`。
  `state.name` は名（会話の `{name}`）。`newState(name, look, profile)` が性格の初期スキルを足し、古いセーブは `loadGame` が
  `defaultProfile(state)`（名＝いまの名前）で補います（`normalizeProfile` で値を正規化）
- データ：`GENDERS` `PREFECTURES`（47）`REGIONS` `PERSONALITIES` `ERAS` `RELATIONS` `CAUSES`、並び順 `PREF_ORDER` `REGION_ORDER` `ERA_ORDER`
  `RELATION_ORDER` `CAUSE_ORDER` `PERSONALITY_ORDER`、候補名 `FAMILY_NAMES` `GIVEN_NAMES` `RELATIVE_NAMES`
- ヘルパー：`eraOf(state)` `ageOf(state)` `fullName(profile)` `profileOf(state)` `personalityOf(state)` `personalityMult(state, 'stress'|'aff'|'lesson'|'rankS')`
  `personalityEffects(id)` `newFamilyMember(rel, familyName, family)` `canAddRelation` `sortFamily` `familyLook(member, playerLook)`（家族の見た目）
  `isBirthday(state)` `daysToBirthday(state)` `birthdayFlag(age)`
- **性格**の効果は1か所ずつ：ストレスの増加（`g.addNeed` の正の stress）、好感度の増加（`g.addAff`。端数は人ごとに `affCarry` で持ち越し）、
  レッスンのスキル（`g.lesson`）、ランク S の知名度（`g.job`）
- **誕生日**：`YEAR_DAYS`（120）日ごと。その朝、`main.js` の朝のフック（コンテンツより先に登録）が `flags['birthday_<年齢>']` を立て、
  トースト・朝のメモと、元気な家族（母→父→ほか）からのメッセージ（`{ family: <家族id>, kind: 'chat' }`）を送ります。家族側（`family.js`）はこのフラグで重複を避けます
- **時代とお金**：内部の金額はどの時代も同じ。表示だけ `ERAS[era].priceRate` 倍して ¥10 単位に丸めます（令和は等倍でそのまま）。
  - `fmtMoney(n)`（`util.js`）が換算ずみの金額を返します。数字の前に見えない印 U+2060（`YEN_MARK`）が入り、二重に換算されません
  - `yenText(str)` は文中の `¥1,500`・`100円`（`100円玉` は除く）を換算します。`g.fmt`（`say` / `ask` / `notify` / スマホのメッセージ）、`g.list` の項目と説明、お店、てちょうが通します。
    自作の描画で文中の金額を出すときは `yenText` を通してください（`fmtMoney` で作った金額はそのままで OK）
  - 換算率は `display.priceRate`。`g.state` を代入したときと毎フレーム、`game.js` が時代から設定します（`util.js` は state を読みません）
- **時代のふんいき**：メニューの「スマホ」は `ERAS[era].device`、スマホの外装（昭和は革の手帳、平成は銀色のケータイ）とガイドは `deviceShort`、
  SNS アプリ（ドッター）の名前は `sns` / `snsShort`（会話中の「ドッター」も `g.fmt` が置きかえ）。新しい作成後には時代の短いオープニング（`title.js` の `EraIntroScene`）
- **キャラクター作成**（`title.js` の `CreateScene`）：新しいゲームは 見た目 → プロフィール → 家族 → かくにん で `resolve({ name, look, profile })`。
  クローゼット（`{ closet: true }`）は見た目のページだけで、いままでどおり `resolve({ name, look })` / `null`。文字入力は `askText`（`textinput.js`）

### 政治の API（`js/engine/politics.js`）

政治のすべて（公職・選挙・政党・国会・内閣・政策と法案・世論・経済・政治資金）のシミュレーション。
`main.js` が起動時に動的 import して `installPolitics(Game.prototype)` で `g.*` を足し（読み込めなくてもゲームは政治ぬきで起動）、`politicsTick` は `onMorning` で毎朝動きます。
画面（`politics_ui.js`）と場所（国会・官邸・党本部・区役所）は、この API と `g.state.politics` だけを使います。
くわしい一覧と事実の出典はファイル先頭のコメントと `g.* API` のブロックにあります。

**原則**：時代と年に合わせた制度（昭和は中選挙区制、1996年から小選挙区比例代表並立制。衆参の定数、2001年の省庁再編、供託金、
被選挙権の年齢、2016年の18歳選挙権、1995年からの政党交付金、2013年のネット選挙）。実在の政党は `jimin`（全時代、ロゴ `jimin`）と
`minshu`（1998〜2016年だけ、ロゴ `minshu`）の2つで、事実だけを中立に。政治家の NPC はすべて架空（生成した名前）。
政策の効果は層ごとの得と損のトレードオフで、どの立場も「正解」にしない。時間：政治の1年＝`YEAR_DAYS`（120日）、1か月＝`MONTH_DAYS`（10日）。

**状態** `g.state.politics`：`{ v, era, cal, me, parties, diet: { shugi, sangi, session, bills }, cabinet, laws, economy, opinion, elections: { upcoming, history }, npcs, flags, local, polls, news, support }`。
`me` は `{ office, district, party, termEnd, posts, faction, wins, losses, funds（政治資金）, secret（裏金）, staff, reputation, localSupport,
standing（党内の評価）, kouenkai, candidacy, campaign, votes, offers, ledger, reported, exposed, formerOffice, sangiClass, prElected, history … }`。
古いセーブは `g.pol()` が初めて呼ばれた時に作られ、足りない項目は補われます。

### 政治の画面（`js/engine/politics_ui.js`）

`politics.js` の HD のフロントエンド（640×360、十字キーと A/B だけ）。コアの `g.*` を呼び、`g.state.politics` を読むだけです。

- `await g.politicsMenu()`：ダッシュボード（スマホの「政治」アプリも同じ）。タブ：選挙・政党・政策・法案・国会・内閣・党内・資金・活動・ニュース
- `await g.politicsScreen(name, opts)`：場所から1画面を直接開く。`'dashboard' 'elections' 'candidacy' { electionId } 'campaign' { electionId } 'parties' 'found' 'policy' 'bills' 'diet' 'cabinet' 'budget' 'formation' 'coalition' 'amendment' 'party' 'money' 'activities' 'news' 'results' 'night' { resultId }（開票速報） 'vote' { billId, house }（本会議の採決）`

- 立候補の届出は「所属 →（衆参なら）立候補のしかた・地元 → 党の選考 → 届出書」。比例代表（参院の比例・衆院の比例単独）でも公認を申請でき、
  見送られたら別のしかたか無所属を選べます。いまの職を失う立候補（公職選挙法90条）は、一覧と届出書に注意が出ます
- `import { openPolitics, politicsScreen, drawEmblem, drawPartyMark } from '../engine/politics_ui.js'`：`drawEmblem(ctx, emblem, x, y, size)`（プレイヤーの党章）、
  `drawPartyMark(ctx, g, partyId, x, y, size)`（ロゴ・党章・色）
- UI だけのデータは `g.state.flags.polui`（経済のグラフ・情勢調査の履歴・夜の出来事の列）。予算編成（`applyBudget`）と民間人閣僚（`ensureCivilian`）だけは状態に直接書きます
- テスト：`g.auto` の間は画面を開かず（`openPolitics` が `null`）、夜の列も捨てます。キーで操作したいときは `g.auto.polui = true`

### 犯罪・司法・借金の API（`js/engine/crime.js`）

犯罪・お金のトラブル・司法（警察・検察・裁判所・刑務所）のシミュレーション。`main.js` が起動時に動的 import して `installJustice(Game.prototype)`（`installPolitics` より先。`crime.js` は `politics.js` を import するので、政治が読めないと司法も外れる）、`justiceTick` は `onMorning`。
くわしい一覧と法律の出典はファイル先頭のコメントにあります（`test-output/api_justice.txt` にも要約）。

**原則**：実際の罪名・条文・法定刑・検挙の見込み・手続きを、その日の法律で（`lawDate(g)`：時代の基準年＋経過年、政治のコアがあれば `g.gameDate()`）。
2025年6月から拘禁刑、2006年の窃盗罪の罰金、2007年の飲酒運転の厳罰化、2010年の総量規制 などが日付で切りかわります。
手口の描写はしない（選択と結果だけ）。テロ・暗殺はプレイヤーの行動にしない（架空の相手が起こす出来事として扱うだけ）。
時間：法律上の短い日数（逮捕48時間＝2日、勾留10日）は1：1、長い日数は `realToGameDays()` で縮め、月と年はゲームの暦（1年＝120日・1か月＝10日）。

**状態** `g.state.justice`：`{ v, status: 'free'|'detained'|'trial'|'prison'|'probation', record[{ crime, day, outcome, months?, fine?, suspend?, label, juvenile? }], heat, custody, prison,
probationUntil, civicBanUntil, candidacyBanUntil, loans[], bankrupt, smoker, flags, cases[], queue[], career{ kinshinUntil, tvBanUntil, agencyBanUntil }, credit{ blackUntil },
income[], garnish, unpaid, suspendUntil, supervision, smoke{} }`。`outcome`：`fine suspended prison acquitted not_indicted bizai hodo warning kare zoun hogo tax_admin juvenile_*`
（前科になるのは `fine` `suspended` `prison`）。

### 社会の裏側の出来事（`js/world/darkside.js`）

ランダムと続きものの出来事 `DARK.EVENTS`（`acc_*` 事故、`inc_*` 事件、`scoop_*` 週刊誌、`pol_*` 政治家への誘い、`hansha_*` 反社、
`threat_*` `crisis_*` 脅迫と危機管理、`debt_*` 取り立て）。毎朝 `decide()` が、プレイヤーの危うさ（`DARK.risk(g)`：闇金・延滞・前科と発覚前の罪・
ネオン街・反社・裏金・知名度・公職）から間隔（3〜9日）と確率（6〜40%）を決め、多くても数日に1つ。最初の6日はなし。
ただの不運（`luck`：交通事故・詐欺の電話・空き巣・ストーカー・脅迫）は知名度と公職の分だけで決まり、危うい暮らしで増えるのは
その暮らしの結果（借金・週刊誌・誘い・反社）のほう。事故どうしは30日以上あけます。選ばれた出来事は
`flags.darkside.pending` で、スクリプトが終わったとき・家で・町を歩いたとき・家に帰ったとき・決まった場所に入ったときを待って始まり、
始める直前にも条件（`ok`）を確かめ直します。
犯罪は `g.commitCrime` / `g.coverUp` / `g.investigate` など司法のコアを通し、どの出来事もまっとうな選択肢が先頭（B と `g.auto` の既定）。
API：`import { DARK } from './darkside.js'`（`window.__dark` も）`DARK.decide(g, { force, only })` `DARK.run(g, id, { data })`（`g.run` の中で）
`DARK.flush(g)` `DARK.schedule(g, id, inDays, data)` `DARK.state(g)` `DARK.risk(g)`。状態は `g.state.flags.darkside`。

**場所**
1. `js/places/<id>.js` に `registerPlace({...})`（上の例）。独自のタイル・アイテム・BGM もこのファイルで
2. `js/registry.js` の `MODULES` に追加
3. 町（`tokyo.js` / `namba.js` / `machi.js` / `minato.js` / `nagatacho.js` / `kanraku.js`）に `{ type: 'building', place: '<id>', ... }` を置く
4. `js/world/guide.js` の `GUIDE` / `GUIDE_ORDER`（お仕事があれば `GUIDE_JOBS`、オーディションなら `AUDITIONS`）に追加。
   町は `town: 'tokyo' | 'namba' | 'nagatacho' | 'kanraku'`（`TOWNS`。てちょうのタグの色は `notebook.js` の `TOWN_BG`）。
   その政党がある時代だけの場所は `party: '<政党ID>'`、行ったときだけ載せる場所（刑務所）は `secret: true`、
   名前がゲームの中で変わる場所（野党・自分の党の本部）は `liveName: true`（行ったあとは `PLACES[id].name` で載る）。
   `registerPlace` されていない場所（作りかけ・読み込み失敗）は、行ったことがなければ「ばしょ」に載りません
5. `node tools/inspect.mjs <id> --out test-output/<id>` で確認

**タイル**：`defineTile('<施設ID>_xxx', { solid, obj, draw, hd })`。新しいタイルには `hd()` を書きます（なければ Scale2x）。

**人**：`js/world/people.js` の `person(id, {...})`（`registerPerson` ＋会話用の既定）で登録し、施設の NPC に `person: '<id>'` を付けます。
ハートイベントは `events: [{ level: 1..4, run }]`（その段階で最初に話した時に1回）、相方候補は `canPartner` ＋ `combi`、
大切な人候補は `special` ＋ `confess` のセリフ（`people.js` の先頭のコメント）。大阪の人は `dialect: 'kansai'`、
ていねい語の人は `polite: true`。朝のメッセージは `messages` / `invites`、おでかけのセリフは `hangout[spotId]`。

**おでかけ先**：`registerHangout(id, {...})`（`machi.js` の例）。演出の絵は `phone.js` の `ART[spotId]`
（なければ夜の街の `_default`）。メッセージの「〜に行かない？」の言い方は `people.js` の `SPOT_WORD`。

**レギュラー番組**：`career.js` の `addShow(id, { ...registerRegular の項目, tier: 1 | 2, kansai, npc: { id, name }, fallbackLook })`。
`addShow` した番組だけがオファーされます（`registerRegular` だけなら、`g.joinRegular(id)` で自分で加える）。
毎週内容を変えたい項目は `dyn(id, { opts: () => ({...}) })` でゲッターに。司会の顔は会場の NPC から取ります。

**家具**：`housing.js` の `FURNITURE_LIST` に `['id', { name, price, desc, perk, ... , paint(c, w) }]`。
絵は 2x ネイティブ（幅 `w*32` px、高さ `artH`、下の 32px が 2x1 タイルの足元）。家具屋の並びは `FURNITURE_ORDER`（＝このリストの順）。
`stamina` は買った時に一度だけ体力の最大値に足されます（`flags.housing_fit`）。

**料理**：`cooking.js` の `RECIPES` に `{ id, name, needs: { ing_xxx: n }, heal, fill, stress, serves, box: false, bento: '〇〇弁当', text }`。

**スマホアプリ**：`registerPhoneApp(id, {...})`。名前は5文字まで、`order` は既定アプリが 10/20/30/40、ドッターが 45。

### テスト

```bash
python3 -m http.server 8765 --directory dot-geinou-v2 &                  # リポジトリのルートで
node dot-geinou-v2/tools/inspect.mjs nhk --out test-output              # 施設の総合チェック（スクショ・会話ログ・到達性）
node dot-geinou-v2/tools/inspect.mjs machi --quick --agency yoshimoto   # 速い版／所属して
node dot-geinou-v2/tools/minigame.mjs quiz --difficulty 1,3,5 --out test-output   # ミニゲームをボットでプレイ
```

ツールは既定で `http://localhost:8765/` を開きます。別のポートなら `GAME_URL=http://localhost:8766/` を指定してください。
スクリーンショットや作業ファイルは `test-output/`（git では無視）に置きます。

**URL パラメータ**：`?test=1&place=nhk&room=studio&x=5&y=6&dir=up`（タイトルを飛ばして直接開始）、`&rich=1`（お金・知名度・スキル多め）、
`&agency=yoshimoto`、`&name=…`、`&intro`（最初の説明も見る）、`&touch`（画面パッドを出す）、
`?minigame=quiz&difficulty=3&skill=talk`（ミニゲーム単体）、`?debug=1`（メニューにデバッグ：ワープ・お金・知名度・スキル・体力・所属・政治・司法と借金）。

**自作の Playwright スクリプト**（Playwright と Chromium が必要。import のパスはスクリプトの場所に合わせる）：`tools/lib.mjs` の `openGame(query)`（ビューポート 1300x800、`{ browser, page, errors }`）、
`shotCanvas(page, file)`、`PAGE_HELPERS`、`loadPlaywright()`。`PAGE_HELPERS` を入れるとリアルタイムのループが止まり、
`await window.__ff(frames)` でだけ進みます（`window.__settle()` はスクリプトが終わってマップに戻るまで進める）。
`window.__game` が Game。`g.auto = { choice: 0 | (choices, pages) => i, list: (items) => i, score: 80, playFrames, log: [] }` で、
会話・選択肢・リストに自動で答え、ミニゲームはそのスコアで終わります（`log` に会話が記録される）。

```js
import { openGame, shotCanvas, PAGE_HELPERS } from './dot-geinou-v2/tools/lib.mjs';
const { browser, page, errors } = await openGame('?test=1&place=home&rich=1');
await page.addScriptTag({ content: PAGE_HELPERS });
await page.evaluate(() => {
  const g = window.__game;
  g.auto = { choice: 0, score: 80, log: [] };
  g.run((g) => g.sleep());       // await しない：__settle が進める
});
await page.evaluate(() => window.__settle());
await shotCanvas(page, 'test-output/me/morning.png');
console.log(errors);
await browser.close();
```

# 熱闘！ポケットベースボール

スマホのブラウザで遊べる野球ゲームです。2004 年の NPB 12 球団・実在選手を題材に、
3D の球場と等身大の選手 (MakeHuman の CC0 人体モデルをもとに生成)、テレビ中継風のテロップで試合を見せます。
効果音・BGM はすべてプログラムで合成しています。端末の性能に合わせて 3D (高・中・低) と従来の 2D 表示を切り替えられます。

## できること

| モード | 内容 |
| --- | --- |
| クイック対戦 | 2004 年の 12 球団から選んで 1 試合。本拠地の球場・ユニフォーム・球団旗、セは DH なし / パは DH あり。先攻・後攻・観戦、3/6/9回、難易度4段階、ナイター/デーゲーム |
| ペナント | セ・パ両リーグを同じ日程で進行 (自チームは所属リーグの 5 球団と対戦、10〜30 試合)。自分で操作するか「おまかせ」で消化。リーグ別の順位表・個人成績 |
| スポーツニュース | ペナントの毎日の試合から記事を作成。目玉は「今日のホームラン」: その日の全試合の本塁打を号数・打点・投手・推定飛距離・状況 (先制/逆転/サヨナラ/満塁/代打/先頭打者/N者連続 など) つきで紹介し、中継風のダイジェストでも見られる。試合結果 (勝敗投手・本塁打欄)・本塁打王争い・首位争い |
| サクセス | 2月〜7月の24週で選手を育成。練習・休養・イベント・仲間との絆・試合イベント（実際に打席やマウンドに立つ）。完成した選手はチームに登録でき、パスワードで書き出し/読み込みも可能 |
| ホームラン競争 | 10アウトまでに何本打てるか。飛距離と自己ベストを記録 |
| 選手名鑑・オーダー | 全選手の能力（S〜Gの8段階・特殊能力）を確認。打順の入れ替え・控えとの交代・先発投手の指名。「守備位置」(グラウンドの図) と「スタメン」(9 枚並び) は選手カードで表示 |
| 選手カード | 選手の写真 (利用者が用意したものから背景だけを抜いたもの) または 3D の選手を切り抜いた絵 (打者はフォロースルー・投手は投げ終わり・捕手は防具をつけた構え。白く縁取る) を、総合ランクに応じた光の背景 (S は金の放射と虹、A は赤い放射、それ以外はスピード線) に重ね、ランクの記章・総合値・背番号・球団マークを入れたカード。選手の詳細・オーダー・今日のホームランのダイジェスト・試合結果の「今日のヒーロー」に登場 |

## 操作（スマホ）

- **打つ**: 画面をなぞると黄色の**ミートカーソル**が動きます。右下の「打つ」でスイング。
  - ボールがカーソルの**上側**に当たるとフライ、**下側**だとゴロ。中心（芯）ほど強い打球。
  - 早く振ると引っ張り、遅いと流し打ち。カーソルの大きさはミート、打球の強さはパワーで決まります。
  - 「バント」「盗塁」ボタンあり。設定で「指を離して打つ」操作やミートアシストも選べます。
- **投げる**: 球種ボタン（矢印＝変化の方向、数字＝変化量）を選び、ゾーンをタップ/なぞってミットを動かして「投げる」。
- **守備・走塁**: 自動。打球に合わせて野手が追い、送球・フォースアウト・タッチアウト・併殺・タッチアップまでシミュレーションします。「早送り」「スキップ」で短縮できます。
- 「タイム」から投手交代・代打・スコアブック確認。横向き画面にも対応しています。
- 画面はテレビ中継風: 左上の SBO カウント (2004 年式) と塁・得点、打者紹介 (きょうの成績)、球速、得点時のスコア、HOME RUN の帯と号数、攻守交代のスコアボードと「今日の結果」。

## 起動方法

### 1. FastAPI サーバーで遊ぶ（同じ Wi-Fi のスマホから）

リポジトリのルートで:

```bash
pip install "fastapi[standard]"
uvicorn pocket_baseball.server:app --host 0.0.0.0 --port 8000
```

スマホのブラウザで `http://<PCのIPアドレス>:8000/` を開きます。
サーバーで遊ぶとセーブデータがサーバーにも保存され（`pocket_baseball/saves/`）、設定画面の「セーブ名」を合わせれば別の端末でも同じデータで遊べます。
保存先は環境変数 `POCKET_BASEBALL_SAVE_DIR` で変更できます。API の一覧は `/api/docs` で確認できます。

### 2. 1つの HTML ファイルにまとめて遊ぶ（サーバー不要）

```bash
python pocket_baseball/tools/build_single.py
```

`pocket_baseball/dist/pocket_baseball.html` (約 7MB) ができます。スマホに送ってブラウザで開くだけで、3D の球場と選手のまま遊べます（セーブは端末内）。
three.js・選手モデル・球団マーク・選手写真もすべて中に入っています。書体だけはネットから読み込み、オフラインでは代わりの書体になります。
古い端末向けに、3D を入れない軽い版 (2D だけ、約 3MB) も作れます: `python pocket_baseball/tools/build_single.py --lite -o pocket_baseball/dist/pocket_baseball_lite.html`

### ホーム画面に追加

サーバー経由で開いた場合は、ブラウザの「ホーム画面に追加」でアプリのように全画面で遊べます（https または localhost ではオフライン用キャッシュも有効になります）。

## しくみ

```

  js/
    util.js     共通関数
    data.js     能力ランク・変化球・特殊能力・選手の生成、実在選手の能力の補正 (D.CALIB)
    npb.js      2004 年の 12 球団 (色・ユニフォーム・帽子・球団旗・本拠地・広告)

    play.js     インプレーのシミュレーション（野手の追跡・捕球・送球・走者の判断・アウト判定）
    ai.js       CPU の配球・スイング判断・作戦（バント/盗塁）・継投、難易度
    game.js     試合進行とスコア・個人成績・勝敗投手・実況の文言・本塁打の記録 (号数・状況)
    chara.js    2頭身キャラの描画
    render.js   簡易3D投影による球場描画（打席カメラ・守備カメラ）と 2D 表示
    three/      three.js による 3D 表示 (stadium.js 球場 / human.js 選手 / gear.js 捕手の防具・グラブ / anim.js 動き / view.js 試合の描画 / portrait.js 選手カード用の切り抜き画像)
    broadcast.js  テレビ中継風のテロップ
    audio.js    Web Audio による効果音・応援・実況ボイス
    match.js    試合画面（タッチ操作・演出・カメラ）
    screens.js / pennant.js / success.js  各モードの画面
    news.js     スポーツニュース・今日のホームラン
    cards.js    選手カード (背景の光・ランク・名前を canvas に描く)
    photos.js   選手写真の一覧 (tools/player_photo.py が生成)
    store.js    セーブ（端末内 + サーバー同期）
    main.js     起動とメインループ
```

打撃・投球・守備はすべて同じ物理エンジンで動いており、CPU 同士の試合（ペナントの他球場の試合など）もこのエンジンを高速に回して決着させています。

## 開発

```bash
# サーバーとエンジンのテスト
pytest pocket_baseball/tests

# CPU 同士で大量に試合をして成績を確認（バランス調整用）
node pocket_baseball/tools/balance.js 100
node pocket_baseball/tools/engine_check.js 24

# ペナント (セ・パ) の日程・本塁打の号数・ニュースの整合性
node pocket_baseball/tools/pennant_check.js t 20
node pocket_baseball/tools/hr_flags_check.js

# 打撃バランス: 2004 年の実成績と本塁打ペースを比べる (係数を JSON で上書きして試せる)
node pocket_baseball/tools/calib_sweep.js '{"ev":{"base":46.3}}' 300

# 選手写真の切り抜き (下の「選手写真」を参照)
python3 pocket_baseball/tools/player_photo.py --dry-run

# ニュース画面の確認 (Playwright・静的サーバーを 8765 番で起動しておく)
node pocket_baseball/tools/pw_news.js http://127.0.0.1:8765/index.html
```

打撃は 2004 年の NPB に近づくよう調整しています: 1 チーム 1 試合あたり約 4.3 得点、打率 .275 前後、1 試合の本塁打は両軍で約 2.2 本。
選手ごとの本塁打ペースが実際の 2004 年の成績と比例するよう (calib_sweep.js の傾き ≈ 1)、打球速度はパワーに対してゆるやかに増え、ばらつきを持たせています。
芯で完璧に捉えたときはパワーの差が大きく出るようにしてあり (投手や非力な打者は完璧でもほぼ柵越えしない)、人が打つときの手ごたえは `node pocket_baseball/tools/swing_probe.js` で確認できます。
能力の補正 (`D.CALIB`) を変えたときは `D.CALIB_VER` を上げると、保存済みのチームの実在選手の能力が名簿から作り直されます (打順や登録した選手はそのまま)。

### 選手写真

選手カードには、用意した写真から選手だけを切り抜いて使えます (写真がない選手は 3D の選手の絵になります)。

1. `pocket_baseball/photos_in/<球団>/<背番号>.jpg` に写真を置く (例: `photos_in/t/6.jpg`。`<球団>` は `t`・`g` などの球団 id か略称、ファイル名は選手名でもよい)。このフォルダは git に入りません。
2. `python3 pocket_baseball/tools/player_photo.py --sheet 確認.jpg` を実行すると、`static/img/players/<球団>_<背番号>.webp` (背景を抜いただけで、色や形には手を加えない切り抜き) と `static/js/photos.js` ができます。
   - 切り抜きは学習済みモデル (ISNet・Apache-2.0。`--model birefnet` で BiRefNet lite・MIT、遅いが細部に強い) を onnxruntime で動かします。初回だけモデルを取得します (`pip install onnxruntime numpy pillow`)。
   - 別の選手が重なっている写真は `photos_in/overrides.json` で `pick` (残す人の位置)・`erase` (消す範囲)・`crop` を指定します。

---

球団名・選手名は 2004 年の日本プロ野球をもとにしています (能力・成績の数値はゲーム独自の査定とシミュレーションの結果です)。
球団マーク・ロゴ・ワードマークの画像と選手写真 (`static/img/players/`) は利用者から提供されたもので、各権利者に帰属します。球場の広告は実在の企業名を使っています。
ニュースの本塁打の飛距離は打球の軌道から求めた推定値で、号数はこのペナントでの本数です。

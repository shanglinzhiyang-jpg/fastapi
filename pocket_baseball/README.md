# 熱闘！ポケットベースボール

スマホのブラウザで遊べる、2頭身キャラの野球ゲームです（パワプロ風のオリジナル作品）。
画像・音声ファイルを一切使わず、球場・キャラクター・効果音はすべてプログラムで描画・合成しています。

## できること

| モード | 内容 |
| --- | --- |
| クイック対戦 | 6球団から選んで1試合。先攻・後攻・観戦、3/6/9回、難易度4段階、ナイター/デーゲーム |
| ペナント | 6球団の総当たりリーグ戦（10/20/30試合）。自分で操作するか「おまかせ」で消化。順位表・個人成績（打率・本塁打・打点・防御率など） |
| サクセス | 2月〜7月の24週で選手を育成。練習・休養・イベント・仲間との絆・試合イベント（実際に打席やマウンドに立つ）。完成した選手はチームに登録でき、パスワードで書き出し/読み込みも可能 |
| ホームラン競争 | 10アウトまでに何本打てるか。飛距離と自己ベストを記録 |
| 選手名鑑・オーダー | 全選手の能力（S〜Gの8段階・特殊能力）を確認。打順の入れ替え・控えとの交代・先発投手の指名 |

## 操作（スマホ）

- **打つ**: 画面をなぞると黄色の**ミートカーソル**が動きます。右下の「打つ」でスイング。
  - ボールがカーソルの**上側**に当たるとフライ、**下側**だとゴロ。中心（芯）ほど強い打球。
  - 早く振ると引っ張り、遅いと流し打ち。カーソルの大きさはミート、打球の強さはパワーで決まります。
  - 「バント」「盗塁」ボタンあり。設定で「指を離して打つ」操作やミートアシストも選べます。
- **投げる**: 球種ボタン（矢印＝変化の方向、数字＝変化量）を選び、ゾーンをタップ/なぞってミットを動かして「投げる」。
- **守備・走塁**: 自動。打球に合わせて野手が追い、送球・フォースアウト・タッチアウト・併殺・タッチアップまでシミュレーションします。「早送り」「スキップ」で短縮できます。
- 「タイム」から投手交代・代打・スコアブック確認。横向き画面にも対応しています。

## 起動方法

### 1. FastAPI サーバーで遊ぶ（同じ Wi-Fi のスマホから）

リポジトリのルートで:

```bash
pip install "fastapi[standard]"
uvicorn pocket_baseball.server:app --host 0.0.0.0 --port 8000
```

スマホのブラウザで `http://<PCのIPアドレス>:8000/` を開きます。
サーバーで遊ぶとセーブデータがサーバーにも保存され（`pocket_baseball/saves/`）、設定画面の「セーブ名」を合わせれば別の端末でも同じデータで遊べます。
保存先は環境変数 `POCKET_BASEBALL_SAVE_DIR` で変更できます。API の一覧は `/api/docs` で確認できます。

### 2. 1つの HTML ファイルにまとめて遊ぶ（サーバー不要）

```bash
python pocket_baseball/tools/build_single.py
```

`pocket_baseball/dist/pocket_baseball.html` ができます。スマホに送ってブラウザで開くだけで遊べます（セーブは端末内）。

### ホーム画面に追加

サーバー経由で開いた場合は、ブラウザの「ホーム画面に追加」でアプリのように全画面で遊べます（https または localhost ではオフライン用キャッシュも有効になります）。

## しくみ

```
static/
  index.html, css/style.css, sw.js, manifest.webmanifest, icon.svg
  js/
    util.js     共通関数
    data.js     能力ランク・変化球・特殊能力・6球団の選手生成（シード固定）
    field.js    球場の座標系と打球の物理（空気抵抗・バウンド・フェンス）
    pitch.js    投球の軌道（変化球・制球のばらつき・疲労）とミートカーソルの当たり判定
    play.js     インプレーのシミュレーション（野手の追跡・捕球・送球・走者の判断・アウト判定）
    ai.js       CPU の配球・スイング判断・作戦（バント/盗塁）・継投、難易度
    game.js     試合進行とスコア・個人成績・勝敗投手・実況の文言
    chara.js    2頭身キャラの描画
    render.js   簡易3D投影による球場描画（打席カメラ・守備カメラ）
    audio.js    Web Audio による効果音・応援・実況ボイス
    match.js    試合画面（タッチ操作・演出・カメラ）
    screens.js / pennant.js / success.js  各モードの画面
    store.js    セーブ（端末内 + サーバー同期）
    main.js     起動とメインループ
server.py       FastAPI（静的配信 + セーブ API）
tools/          バランス調整・検証用スクリプト、1ファイル化スクリプト
tests/          サーバーとエンジンのテスト
```

打撃・投球・守備はすべて同じ物理エンジンで動いており、CPU 同士の試合（ペナントの他球場の試合など）もこのエンジンを高速に回して決着させています。

## 開発

```bash
# サーバーとエンジンのテスト
pytest pocket_baseball/tests

# CPU 同士で大量に試合をして成績を確認（バランス調整用）
node pocket_baseball/tools/balance.js 100
```

CPU 同士の試合の成績は、打率 .250〜.280、1試合あたり 3.5〜5 得点、本塁打 0.6〜1.0 本、三振率 15〜20% 程度になるよう調整しています。
